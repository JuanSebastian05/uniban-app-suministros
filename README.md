# Uniban App Suministros

Repositorio para la realización del proyecto **Uniban – Proyecto Integrador 1 de la Universidad de Antioquia (UdeA)**.

## Estado actual del proyecto

Actualmente, el repositorio contiene los principales documentos y artefactos iniciales para la definición y planeación de la solución:

- Anteproyecto inicial del equipo.
- Requisitos funcionales y requisitos técnicos.
- Historias de usuario.
- Modelo entidad-relación de la base de datos.
- Mockups iniciales de la aplicación realizados en Figma.
- Estructura base del repositorio para organizar la documentación del proyecto.
