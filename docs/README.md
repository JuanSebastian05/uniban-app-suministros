## Dónde agregar documentación

Guarda cada documento en la carpeta de su tema y enlázalo desde este índice si sirve como punto de entrada. Las decisiones vigentes pertenecen a las guías, contratos e historias; los archivos de `avances/` conservan las entregas históricas. Mantén los enlaces relativos al documento que los contiene.
